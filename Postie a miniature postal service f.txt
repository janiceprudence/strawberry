Postie: a miniature postal service for feelings.
The core experience
The sender records a voice note, wraps it like a parcel, adds a tiny label, then “posts” it. The recipient finds it waiting in a cozy mailbox and opens it with a small tactile animation.
The emotional sequence:
	1. Record it 
	2. Wrap it 
	3. Send it 
	4. Find it waiting 
	5. Open and listen 
	6. Send a little reaction parcel back 
No public feeds, likes, or performance. Just one person sending something warm to another.

Custom display lettering
Start with the general character of Berkshire Swash, but change it substantially:
	• Reduce the overall stroke weight by roughly 50–60%. 
	• Use near-monoline strokes with only slight pressure variation. 
	• Lengthen the entry and exit strokes. 
	• Give capitals one memorable looping flourish. 
	• Make lowercase letters small, loose, and slightly irregular. 
	• Open up counters in letters like a, e, and o. 
	• Avoid thick retro terminals and overly perfect wedding-calligraphy forms. 
	• Let occasional letters dip below the baseline like loose handwriting. 
	• Keep the lettering intimate and youthful—not luxurious or formal. 
Think: a love note written with a fine red gel pen.
For the project name, I would create a custom wordmark rather than an entire font. That gives us much more personality without the enormous work of designing every character.
Best pairing
	• Project wordmark: custom thin swash lettering 
	• Special buttons: a simplified matching script 
	• Parcel typography: Lora 
The brand could look delicate and expressive, while Lora keeps the actual correspondence grounded and readable.
Button treatment
For buttons, avoid the wordmark’s most extreme flourishes. The lettering should have:
	• A slightly heavier stroke than the logo 
	• No overlapping loops 
	• Shorter ascenders and descenders 
	• Generous spacing around the text 
	• Dark cherry lettering on a cream or pink button 

.brand {
  font-family: "Custom Postie Script", cursive;
  font-weight: 300;
  letter-spacing: 0.01em;
}
.script-button {
  font-family: "Custom Postie Script", cursive;
  font-size: 1.45rem;
  font-weight: 400;
  line-height: 1;
}
Temporary fonts for the prototype
Until we create the custom lettering, I’d test:
	1. MonteCarlo — my first choice; thin, looping, romantic, and fairly restrained. 
	2. Italianno — looser and more handwritten. 
	3. Mrs Saint Delafield — very airy and whimsical, best for the project name rather than buttons. 
	4. Allura — the safest and most legible option, though less distinctive.

Update the website typography system with two clearly defined font roles.
	1. Display script font
Use a delicate, romantic handwritten script for:
	• The project name and wordmark
	• Short primary CTA labels
	• Occasional decorative phrases
The visual direction should be inspired by fine-pen love-letter handwriting: thin, airy strokes, gentle pressure variation, long entry and exit strokes, restrained loops, and slightly imperfect letterforms.
Do not use Berkshire Swash. It is too heavy and retro for this direction.
For the working prototype, use "MonteCarlo" from Google Fonts with a cursive fallback. Treat it as a temporary substitute for a future custom wordmark.
The script should feel:
	• Delicate and youthful
	• Handwritten with a fine red ink pen
	• Romantic without resembling formal wedding calligraphy
	• Expressive but still readable
	• Light, with generous space around the letters
Do not artificially make the font thinner with opacity, transforms, text shadows, or CSS outlines. Use its native font weight.

Readability requirements:
	• Use the script only for short phrases of approximately one to four words.
	• Do not use the script for paragraphs, timestamps, navigation, form fields, error messages, or accessibility instructions.
	• Use Lora for utility controls such as “Pause,” “Delete,” “Settings,” and “Try again.”
	• Script CTA labels must remain readable at mobile sizes.
	• Give script buttons generous horizontal padding so flourishes do not touch their edges.
	• Avoid all-uppercase text in the script font.
	• Do not apply additional letter spacing to connected script lettering unless visual testing shows it is necessary.
	• Preserve sufficient color contrast against the cream and pink backgrounds.
	• Ensure visible keyboard focus styles are not obscured by decorative flourishes.
	• Keep accessible names concise and functional, even when the visible CTA uses playful wording.
